# Журнал технических решений

Все записи ниже относятся к 4 ноября 2026. Исполнитель: Codex по поручению Антона.
Это технические решения пилота; они не выданы за решения обоих участников команды.

1. **Отдельная папка и venv.** Все новые файлы в `dlinear-as-is`, Python из
   `/usr/bin/python3` используется только для создания отдельной `.venv`.
   Системные site-packages отключены. Альтернатива — менять учебное окружение —
   не выбрана из-за прямого запрета затрагивать существующие рабочие настройки.
2. **Код без правок.** Сохранён официальный репозиторий и точный commit.
   Вместо переноса/переписывания DLinear запускается авторская точка входа.
   Внешняя обёртка только задаёт аргументы, папку, среду, логирование и лимит времени.
3. **Совместимое окружение.** Сохранён PyTorch 1.9.0; найден официальный macOS
   ARM64 wheel. Использован уже доступный Python 3.9.6, чтобы не устанавливать
   новый глобальный интерпретатор. NumPy 1.23.5/pandas 1.5.3 совместимы со старым
   API исходников. Для отсутствующих в upstream ограничений выбраны версии,
   все транзитивные пакеты закреплены хешами после разрешения зависимостей.
4. **Загрузка.** Только официальные GitHub/PyPI. Пакеты скачаны как wheels,
   SHA-256 сверены с API PyPI до установки. Данные — один CSV из ETDataset по
   commit; лицензия и README сохранены. Установка пакетов выполнена офлайн
   из скачанных файлов. Предобученные чужие веса не использовались.
5. **Один пилот.** Выбрана первая конфигурация авторского etth1.sh: 336 → 96.
   Максимум 10 эпох и early stopping оставлены исходными. Остальные горизонты
   и трансформеры сейчас не запускались, чтобы держаться согласованного объёма.
6. **CPU и workers.** num_workers=0 вместо авторского default 10; основной
   авторский файл не защищён main guard для spawn. Выбрано изменение CLI
   параметра вместо правки исходников. Потоки CPU ограничены двумя.
7. **План до результатов.** BEFORE_RUN.md записан до первого обучения.
   Зафиксированы технические ожидания, а не численные исследовательские ставки
   от имени команды. Будущие планы должны учитывать уже известный пилот.
8. **Проверки после запуска.** Независимо восстановлены цели и нормализация;
   проверены метрики, число окон и соответствие checkpoint прогнозам.
   Второй запуск с тем же seed проверяет повторяемость, не заменяет 3 сида.
9. **Файлы сохраняются.** Новые запуски идут в новые каталоги, старые не удаляются.
   Авторский EarlyStopping обновляет собственный checkpoint внутри нового запуска;
   никаких прежних файлов пользователя этот путь не использует.
10. **Корректировка обёртки.** После pilot-01 добавлены PIP_CACHE_DIR и
    PIP_DISABLE_PIP_VERSION_CHECK для команды фиксации окружения: pip предупреждал
    о недоступном пользовательском cache. Это не меняет обучение; исходники
    автора остались нетронутыми. SHA-256 версии обёртки сохранён для каждого запуска.
11. **Первоначально публикация отложена.** В GitHub ничего не отправлялось, существующий
    репозиторий Антона не изменён. Результат подготовлен локально для просмотра.

12. **Подготовка публикации по просьбе Антона.** Авторский код подключён submodule
    по проверенному коммиту. Публикуются скрипты, lock, конфигурация и текстовые
    свидетельства двух запусков; окружение, CSV, wheels и бинарные артефакты
    остаются локально. В логах/metadata абсолютный путь заменён на ${PROJECT_ROOT}.
    Для свежего clone загрузчик данных проверяет существующий опубликованный
    манифест, а обёртка создаёт локальные папки кэшей и вывода. Модель не менялась.
