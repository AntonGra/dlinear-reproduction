# Журнал решений

## 4 ноября 2026: пробный запуск

- **Исходники.** Авторский LTSF-Linear подключён как submodule по коммиту
  `0c113668a3b88c4c4ee586b8c5ec3e539c4de5a6`. Код модели и обучения оставлен без правок.
- **Конфигурация.** Для первого запуска взята готовая команда ETTh1 336 → 96
  из `scripts/EXP-LongForecasting/Linear/etth1.sh`. Остальные горизонты
  и сравнение с трансформерами отложены до основного эксперимента.
- **Окружение.** Python 3.9.6 вместо указанного авторами 3.6.9: эта версия уже
  доступна на машине. PyTorch сохранён 1.9.0. Остальные зависимости закреплены
  отдельно, поскольку в upstream их версии не заданы. NumPy 1.23.5 поддерживает
  `np.Inf`, который используется в авторском EarlyStopping.
- **Выполнение.** CPU, 2 потока, `num_workers=0` вместо 10. Это позволяет
  запускать исходную точку входа на macOS без добавления main guard для spawn
  и ограничивает нагрузку. Гиперпараметры обучения не менялись.
- **Повтор.** Та же конфигурация повторно запущена с seed 2021 для проверки
  воспроизводимости. Прогнозы совпали побитово; это не оценка разброса по сидам.
