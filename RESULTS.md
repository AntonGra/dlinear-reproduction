# Пробный запуск DLinear на ETTh1

4 ноября 2026. Apple M4 Pro, 48 GB RAM, macOS 26.6.2, CPU, 2 потока.

## Конфигурация

Авторский код LTSF-Linear, commit `0c113668a3b88c4c4ee586b8c5ec3e539c4de5a6`,
без изменений. ETTh1, multivariate: 7 переменных, вход 336 часов, прогноз 96 часов.
`batch_size=32`, `learning_rate=0.005`, Adam, MSE, `seed=2021`,
`train_epochs=10`, `patience=3`, `individual=False`.

Данные разделены исходным загрузчиком: 8640/2880/2880 строк для
train/validation/test. Нормализация рассчитана только на train.
Из 17420 строк CSV используются первые 14400; оставшиеся строки не входят
в этот эксперимент по авторской схеме разбиения.

Окружение: Python 3.9.6, PyTorch 1.9.0, NumPy 1.23.5, pandas 1.5.3,
scikit-learn 1.2.2, SciPy 1.10.1, matplotlib 3.7.5.
[Полный список версий](runs/pilot-01/environment.txt).

## Ограничения

Это один датасет, один горизонт и один seed. Повтор с тем же seed проверяет
повторяемость, но не разброс по независимым запускам. Трансформеры не запускались,
сравнение с таблицей статьи пока не выполнялось.

В выбранном коммите `drop_last=False` для теста уже установлен.
Исправлений оценки в рамках этого запуска не было. Validation loader использует
`shuffle=True`, `drop_last=True`; early stopping выбирает модель по validation loss.
