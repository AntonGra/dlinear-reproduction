# Результат технического пилота

Дата: 4 ноября 2026. Подготовлено Codex; участникам нужно ознакомиться перед сдачей.

**Запуск успешен.** Оригинальный код DLinear в зафиксированной версии выполнен
без редактирования исходников, на CPU Apple M4 Pro (48 GB RAM, macOS 26.6.2).
Изменения окружения и параметров выполнения перечислены ниже и в DECISIONS.md.

## Конфигурация

ETTh1, multivariate (7 входных и 7 прогнозируемых переменных), вход 336 часов,
прогноз 96 часов, batch_size=32, learning_rate=0.005, Adam, MSE,
seed=2021, максимум 10 эпох, patience=3, individual=False.
Набор данных: 17420 строк, без пропусков и повторов времени, шаг 1 час.
Использован исходный хронологический split автора: 8640/2880/2880 строк
train/validation/test; остаток файла авторский loader в этом эксперименте не использует.
Контекст для validation/test берётся из предшествующей истории, целевые значения
относятся к своему разделу. Нормализация обучена только на первых 8640 строках.

## Ограничения и полезные особенности авторского кода

- Это один датасет, один горизонт, одна модель и один seed. Второй запуск —
  проверка повторяемости, **не второй независимый seed**. Требование к основному
  результату исследования (минимум 3 сида) этим пилотом не закрыто.
- Трансформеры не запускались; результат не доказывает преимущество DLinear.
- Совпадение с таблицей статьи не оценивалось. Таблица в `LTSF-Benchmark.md`
  прямо описана как результаты с best input length; здесь окно фиксировано в 336.
  Авторы также предупреждают в README об обновлении скриптов и чисел.
- В выбранном коммите test `drop_last=False` уже установлен. Не следует
  писать, что в этой работе такой баг был обнаружен и исправлен.
- Validation loader исходно использует shuffle=True, drop_last=True.
  На каждой эпохе авторский код выводит также test loss, но early stopping
  принимает только validation loss. Мы не меняли настройки по тестовым числам.
- Среднее батчевых loss в строках эпох и финальное MSE — разные способы
  агрегирования при неполном последнем батче. Финальные метрики относятся к
  восстановленному лучшему checkpoint, не обязательно к последней эпохе.
- Python 3.9.6 вместо 3.6.9; PyTorch сохранён 1.9.0. Прочие пакеты закреплены
  нами, поскольку upstream не задаёт их версии. NumPy 1.23.5 сохраняет `np.Inf`,
  используемый исходным EarlyStopping.
- `num_workers=0` вместо 10 предотвращает необходимость править main guard
  под macOS multiprocessing и ограничивает нагрузку. CPU, 2 вычислительных потока.
