# План технического запуска — записан до обучения

Дата: 4 ноября 2026, Europe/Moscow. Подготовлено Codex по поручению Антона.

Цель: проверить локальный запуск оригинальной DLinear и сохранить воспроизводимые
артефакты для пункта 3 pre-registration. Это технический пилот, не законченная
проверка гипотезы статьи и не pre-registration от имени участников.

- Код: cure-lab/LTSF-Linear, commit 0c113668a3b88c4c4ee586b8c5ec3e539c4de5a6.
- Данные: ETTh1, официальный zhouhaoyi/ETDataset,
  commit 1d16c8f4f943005d613b5bc962e9eeb06058cf07, ETT-small/ETTh1.csv.
- Первая команда из scripts/EXP-LongForecasting/Linear/etth1.sh:
  multivariate, seq_len=336, pred_len=96, batch_size=32, learning_rate=0.005,
  itr=1, seed=2021, максимум 10 эпох, early stopping patience=3.
- Выполнение на CPU, num_workers=0 вместо 10: ограничение нагрузки и отсутствие
  multiprocessing spawn без main guard на macOS. Модель и обучение не меняются.
- Ожидание: исходники запустятся с PyTorch 1.9.0 и совместимыми версиями пакетов;
  получим конечные MSE/MAE, локальный checkpoint и прогнозы для всех тестовых окон.
- Критерий технического успеха: exit code 0, конечные прогнозы правильной формы,
  независимый пересчёт MSE/MAE совпадает с логом, число прогнозов равно числу
  тестовых окон, исходники не изменены. При сбое сохранить лог, причину и правки.
- После первого успешного запуска повторить ту же конфигурацию с тем же seed
  в новой папке для проверки повторяемости. Это не два независимых сида.
- Бюджет пилота: два последовательных запуска, до 15 минут каждый; 2 CPU-потока.
  При превышении выяснить причину, не менять гиперпараметры ради цифр.

Численное ожидание относительно таблицы статьи здесь не заявлено: авторский
benchmark использует best input length, а текущий пилот фиксирует окно 336.
Будущие исследовательские ожидания и критерии сравнения участники формулируют
до соответствующих экспериментов, учитывая, что результаты пилота уже известны.
